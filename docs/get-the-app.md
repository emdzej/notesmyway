Notes my Way is being prepared for the App Store. This page will link to it as soon as it's there.

## What you'll need

| Device | System |
| --- | --- |
| iPhone | iOS 26 or later |
| iPad | iPadOS 26 or later |
| Mac | macOS 26 or later |

No account, no sign-up. You'll need a folder of Markdown files — or an empty folder to start one. It can be in iCloud Drive, on your device, or anywhere the Files app and Finder can reach.
