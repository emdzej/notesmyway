# Getting started

Notes my Way works on a **notebook**: any folder of Markdown files. Every note is a `.md` file in it, and subfolders are folders of notes. Nothing is imported or copied — the app reads and writes the files where they are.

## Open a folder

**On the Mac**, choose **Open a Folder as Notebook…** on the welcome screen, or **File › Add Notebook…** later, and pick a folder in Finder.

**On iPhone and iPad**, tap **Open a Folder as Notebook…** and pick a folder in the Files picker: iCloud Drive, On My iPhone, or a provider such as Dropbox. To start fresh, create a new folder right there in the picker.

The first time a notebook opens, the app reads every note to build its index for search, tags and backlinks. After that it only re-reads files that changed.

## Find your way around

- **Sidebar:** All Notes, Pinned, the notebook's folders and its tags. The menu at the top switches notebooks.
- **Note list:** the notes in the selected folder or tag, pinned ones first, with the date, the first lines and the first image.
- **Editor:** the note itself. Formatting is shown in place; see [Writing](/guide/writing).

On iPhone the three appear one after another; on iPad and Mac side by side.

## Your first note

Press **⌘N** on the Mac, or tap the compose button. The note is created in the selected folder as `Untitled.md`; its first `# heading` becomes its title in the list. Notes save themselves half a second after you stop typing.

## Open a single file

A `.md` file that isn't in a notebook opens on its own: from Finder's **Open With** (or a double-click, once Notes my Way is the default app for Markdown), **File › Open File… (⇧⌘O)**, or the Files app on iPhone and iPad. If the file is inside a notebook you've added, it opens there instead.
