# Settings and shortcuts

**Settings** opens with **⌘,** on the Mac. On iPhone and iPad, tap the gear at the top of the sidebar, or **Settings…** in the notebook menu.

## General

Applies to the app on this device.

| Setting | Options |
| --- | --- |
| Appearance | System, Light, Dark |
| Sidebar | System Default, My Way |
| Notes open as | Formatted, Markdown Source |
| Theme | the editor's [theme](/guide/themes), font, text size and line spacing |
| Markdown source theme | the same as the editor, or another theme |
| Markdown files (Mac) | which app opens `.md` files, and a button to make it Notes my Way |

## Notebook

Saved inside the notebook (`.nmw/config.json`), so the settings travel with it.

| Setting | Default |
| --- | --- |
| Attachments folder name | `.attachments` |
| Attachments location | next to the note |
| Show attachment folders in the sidebar | off |
| Load previews for web links | on (only links marked `{.preview}`) |

## Keyboard shortcuts (Mac)

| Shortcut | Action |
| --- | --- |
| ⌘N | New note |
| ⌘O | Open quickly (note switcher) |
| ⇧⌘O | Open a Markdown file |
| ⌘L | Link to note |
| ⇧⌘M | Formatted / Markdown source |
| ⇧⌘K | Show the link at the caret as a preview card |
| ⌥⌘I | Outline and backlinks |
| ⌫ | Move the selected note or folder to the trash |
| ⌘, | Settings |

The formatting shortcuts are listed under [Writing](/guide/writing#the-format-menu-mac).
