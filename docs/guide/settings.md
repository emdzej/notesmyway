# Settings and shortcuts

**Settings** opens with **⌘,** on the Mac. On iPhone and iPad, tap the gear at the top of the sidebar, or **Settings…** in the notebook menu.

Settings has four tabs on the Mac, and the same four pages on iPhone and iPad. The first three apply to the app on this device.

## General

| Setting | Options |
| --- | --- |
| Notes open as | Formatted, Markdown Source |
| Move checked items to the bottom | off |
| Markdown files (Mac) | which app opens `.md` files, and a button to make it Notes my Way |

## Appearance

| Setting | Options |
| --- | --- |
| Theme | the [theme](/guide/themes), which colors the whole app |
| Appearance | System, Light, Dark (fixed by themes made for one mode) |
| Sidebar | System Default, My Way |
| Font, Text size, Line spacing | the editor's text |
| Markdown source | the same theme as the editor, or another one |

## Themes

Installed themes, with **Install Theme…**, **Duplicate**, **Share** and **Delete**. See [Installing themes](/guide/themes#installing-themes).

## Notebook

Saved inside the notebook (`.nmw/config.json`), so the settings travel with it.

| Setting | Default |
| --- | --- |
| Attachments folder name | `.attachments` |
| Attachments location | next to the note |
| Show attachment folders in the sidebar | off |
| Load previews for web links | on (only links marked `{.preview}`) |
| Rename files to match the first heading | off |

With **Rename files to match the first heading** on, a note's file follows its first `# heading`: after you pause typing (about 1.5 seconds) or leave the note, `Untitled.md` becomes `Trip to Lisbon.md`. Links to it are updated and the banner offers **Undo**; undoing keeps the old name for that heading. Notes without a heading, headings starting with "Untitled", and names already taken are left alone. Characters a file name can't hold (`/`, `:`) become `-`.

## Keyboard shortcuts (Mac)

| Shortcut | Action |
| --- | --- |
| ⌘N | New note |
| ⌘O | Open quickly (note switcher) |
| ⇧⌘P | Command palette |
| ⇧⌘O | Open a Markdown file |
| ⌘L | Link to note |
| ⇧⌘M | Formatted / Markdown source |
| ⇧⌘K | Show the link at the caret as a preview card |
| ⌥⌘I | Outline and backlinks |
| ⌫ | Move the selected note or folder to Recently Deleted (in Recently Deleted: delete now) |
| ⌘, | Settings |

The formatting shortcuts are listed under [Writing](/guide/writing#the-format-menu-mac).
