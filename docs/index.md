## Your files, not a database

A notebook is any folder of Markdown files. Folders are real folders, attachments are ordinary files next to the notes, and the app watches the folder, so a note edited elsewhere shows up right away. Grep it, put it in git, open it in another app — it's still the same note.

[Notebooks and folders →](/guide/notebooks)

## Markdown that stays out of the way

Formatting renders in place and the markers come back on the line you're editing. The bar above the keyboard on iPhone and iPad, and the Format menu on the Mac, write the Markdown for you. One shortcut, ⇧⌘M, shows the source with syntax colours.

[Writing →](/guide/writing)

## Tables that add up

Tables are an editable grid: add rows and columns from the markers on the edges, drag borders to set widths. Cells can hold formulas — `SUM`, `AVERAGE`, `IF` and more — in the same syntax as the VitePress formula plugin, so the numbers match when you publish.

[Tables and formulas →](/guide/tables)

## Make it yours

Seven themes, from the teal default to a serif Paper. Each one colors the whole app: the note page, the note list, the sidebar and the accent, in light and dark. Install new themes by opening a `.nmwtheme` file, or make your own from a JSON file.

[Themes and appearance →](/guide/themes)
