features:
  - title: Your files, not a database
    details: A notebook is any folder of Markdown files. Open it with vim, grep it, put it in git — nothing is locked inside the app. The search index is disposable and rebuilds itself.
  - title: Markdown that stays out of the way
    details: Formatting renders in place and the markers come back on the line you're editing. One shortcut (⇧⌘M) switches to plain, highlighted Markdown source when you want to see every character.
  - title: Tables you can actually edit
    details: Tables are an editable grid — add rows and columns from the markers on the edges, drag borders to set widths, align columns from a handle. On disk it's still a GFM table.
  - title: Images and link cards
    details: Drop a file in and it lands in the note's attachment folder. Resize images and turn links into preview cards from the context menu or the small bar over them; the choice is saved as {.medium}-style attributes.
  - title: Links that survive renames
    details: Notes link to each other with ordinary relative links that work on GitHub too. Rename or move a note and every link to it is updated — with a one-click undo.
  - title: Native on Mac, iPhone and iPad
    details: SwiftUI and TextKit 2, no web views in the editor. Folders, tags, pinned notes, search, backlinks and an outline, the way you'd expect from an Apple app.
