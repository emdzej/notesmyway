# Welcome to Notes my Way

Every note here is a plain **Markdown** file in a folder you chose. Open the folder in Finder, edit a note in any app, and it's still the same note.

## Try these

- [x] Open a folder as a notebook
- [ ] Pin a note you use every day
- [ ] Tag a note and find it in the sidebar
- [ ] Press ⇧⌘M to see the Markdown source

> Your notes stay plain `.md` files you can open anywhere.
